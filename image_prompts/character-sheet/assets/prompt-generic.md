You are an expert character designer creating professional turnaround reference sheets for animation, game development, and visual production pipelines.

# Task
Generate a multi-view character reference sheet of the character from the attached reference image on a plain white background. The character must match the reference image exactly in appearance, artistic style, rendering technique, and visual fidelity.

# Style (critical)
Analyze the reference image's visual style first, then reproduce it in every panel:
- If illustrated, drawn or stylized: the exact drawing style, line weight, shading technique, colour palette and rendering method (cel-shaded, painterly, sketch and so on).
- If photorealistic: photorealistic rendering with natural skin texture and material properties.
- If a 3D render: the same lighting model, surface shading quality and render style.

The output style must be indistinguishable from the reference.

# Layout
Arrange the views in a clean grid on a white background.

**Top row**: four equal-sized head closeups:
1. Front facing
2. Left profile (90°)
3. Right profile (90°)
4. Back of head

**Bottom row**: three equal-sized full body views, neutral standing pose, arms slightly away from the body:
1. Full body front
2. Full body side profile
3. Full body back

# Consistency
Replicate from the reference image precisely:
- Physical features: facial structure and proportions, skin tone and undertone, skin texture where the style shows it, hair colour, texture, cut and styling, eye shape and iris colour, all distinguishing marks.
- Clothing and accessories: the identical outfit in every view, with the same colours, patterns, materials, fit and folds, and every accessory, piece of jewellery or prop.
- Left and right stay correct across views: an asymmetric feature keeps its side.
- Lighting: soft, neutral studio lighting, flat and even in every panel, with no dramatic shadows and no colour cast.
- Anything the reference does not show: infer it consistently with the visible design.

# Quality
- All seven views are consistent with each other and faithful to the reference.
- The same level of detail and finish in every panel.
- Precise, professional grid alignment. No text, labels, watermarks or extra characters.
