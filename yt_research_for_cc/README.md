# YouTube Research Skills for Claude Code

Three Claude Code Agent Skills that chain together into an unattended YouTube
research pipeline. Each folder here is a working copy of what's installed at
`~/.claude/skills/<name>/` on this machine — vendored into the repo so the setup
is reproducible and version-controlled.

| Skill | Does | Depends on |
|---|---|---|
| **[`yt-search/`](yt-search)** | Searches YouTube via `yt-dlp`, returns structured/`--json` results with title, channel, subs, views, duration, upload date, URL, and a views-to-subscribers engagement ratio. | `yt-dlp` |
| **[`notebooklm/`](notebooklm)** | Full programmatic access to Google NotebookLM — notebooks, sources (including YouTube URLs), chat, and every artifact type (podcast, video, slide deck, report, quiz, flashcards, infographic, mind map, data table). Vendored from the third-party [`notebooklm-py`](https://github.com/teng-lin/notebooklm-py) package's `notebooklm skill install` output, not hand-written here. | `notebooklm-py` CLI + a Google account |
| **[`yt-pipeline/`](yt-pipeline)** | Orchestrates the other two: topic → yt-search → auto-select 5-8 best videos (relevance/engagement/recency/diversity) → NotebookLM notebook → trends/outliers/gaps analysis → optional podcast/slides/report → vault research note. Runs unattended, no confirmation pauses. | `yt-search`, `notebooklm` |

## Install

Copy each folder to `~/.claude/skills/<name>/` (Claude Code auto-discovers skills
there and triggers them by description — no slash command registration needed).

### 1. yt-search

```bash
pip install yt-dlp
```

No further setup — the skill resolves `yt-dlp` on PATH or as `python -m yt_dlp`
automatically.

### 2. notebooklm

This skill's content is generated by the `notebooklm-py` package itself, not
authored in this repo — reinstall it from upstream rather than hand-editing:

```bash
pip install "notebooklm-py[browser]"
notebooklm skill install          # (re)installs ~/.claude/skills/notebooklm/SKILL.md
notebooklm login                  # opens a browser for one-time Google sign-in
notebooklm auth check --test --json   # verify: expect "status": "ok" and checks.token_fetch: true
```

If you update `notebooklm-py`, re-run `notebooklm skill install` and re-copy the
result into `setup/skills/notebooklm/` here to keep the repo copy in sync.

### 3. yt-pipeline

No separate install — it's pure orchestration over the two skills above via
`scripts/select_videos.py`, which locates `yt-search`'s script as a sibling under
`~/.claude/skills/yt-search/scripts/search.py`. Both skills must be installed
side by side under the same `~/.claude/skills/` directory.

## Verify end to end

```bash
# yt-search
python ~/.claude/skills/yt-search/scripts/search.py "claude code skills" --count 3 --json

# notebooklm
notebooklm auth check --test --json

# yt-pipeline (search + score + select, no NotebookLM calls yet)
python ~/.claude/skills/yt-pipeline/scripts/select_videos.py "claude code skills" --count 15 --months 6 --json
```

Then ask Claude Code something like *"research 'claude code skills' on YouTube and
give me a briefing report"* — `yt-pipeline` should trigger automatically and run
through search → selection → notebook → analysis → report with no pauses.

## Keeping the repo copy in sync

`yt-search` and `yt-pipeline` are authored in this repo — edit them here (or in
`~/.claude/skills/`) and copy changes both directions so the two stay identical.
`notebooklm` is vendored from `notebooklm-py`'s `notebooklm skill install` output —
never hand-edit it; regenerate and re-copy instead.
